# 수학천재 FREE 중학교 1·2·3학년 개념 학습

초등 1~6학년 **기존 App 코드는 그대로 유지**하면서 중학교 1~3학년 전용 학습실을 추가했습니다. GitHub Pages에서 DB 없이 동작합니다.

## 제공 범위
- 중1: 소인수분해, 정수와 유리수, 문자식·일차방정식, 좌표평면, 비례, 도형과 부채꼴, 입체도형, 자료·통계
- 중2: 순환소수·지수법칙, 일차부등식·연립방정식, 일차함수, 삼각형·사각형, 닮음, 피타고라스 정리, 경우의 수·확률
- 중3: 제곱근·무리수, 근호 계산, 다항식·인수분해, 이차방정식·이차함수, 삼각비·원의 성질, 산포도·상자그림·산점도
- 총 **34개 단원**, 매 단원 **개념 설명 → 숫자·그래프·도형 조작 → 객관식 문제 풀이 및 풀이 해설**
- 단원 완료는 `localStorage` 키 `mathgenius.middle.completed.v1`에만 저장합니다. 회원·DB 서버/API는 없습니다.
- 학교급 전환: 초등 학습실 상단의 **중1, 중2, 중3 수학** 버튼 또는 `/?level=middle&grade=1` 등.

## 교육과정 적용 참고
교육부 고시 제2022-33호 수학과 교육과정(별책 8)을 참고한 **자체 단원 구성**입니다. 교육과정은 2025학년도 중1, 2026학년도 중2, **2027학년도 중3부터** 순차 적용됩니다. 교과서/학교별 단원명과 배치에는 차이가 있습니다. 원문: https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458

## 사이트 분석
Cloudflare Web Analytics는 원본 첫 화면과 모든 정적 교육과정 안내 페이지에 동일하게 포함합니다. 개인정보나 문제 풀이 결과를 추적 이벤트로 보내지 않습니다.

## 테스트
`npm run build`, `npm test`, `npm run test:ui`, `npm run test:viewport`. 랜덤 문제 3,400회를 생성하여 정답 선택지/보기 유일성 및 풀이를 검증합니다.

교육부·교육청 공식 인증/운영이 아니며 학습 사이트의 자체 콘텐츠입니다.
