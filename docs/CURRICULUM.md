# 전체 학년·학기 수학 커리큘럼

2026년 기준 적용되는 2022 개정 초등 수학과 교육과정에 맞춰 초등 1~6학년의 **1·2학기 총 71개 교재형 단원**을 관리합니다.

학년·학기별 구성은 교재형 단원 분류이며 **국가 교육과정의 성취기준과 1:1 대응하는 분류가 아닙니다.** 학교나 출판사에 따라 단원 순서·명칭이 달라질 수 있습니다.

## 국가 교육과정 성취기준 연결

2022 개정 수학과 교육과정의 초등 성취기준은 총 121개이며, 학년군별 코드 개수는 다음과 같습니다.

| 학년군 | 코드 접두어 | 성취기준 수 |
| --- | --- | ---: |
| 1~2학년군 | `2수` | 29 |
| 3~4학년군 | `4수` | 47 |
| 5~6학년군 | `6수` | 45 |
| **합계** | | **121** |

`src/standards.ts`에는 모든 코드와 관계있는 단원 ID가 매핑되어 있습니다. `npm test`는 코드 개수, 중복, 없는 단원 참조, 연결 누락을 검사합니다.

### 개발 단계와 완성도

- **구현됨:** 71개 학년·학기·단원 탐색, 각 단원의 첫 개념 안내와 문제 출제·풀이, 83개 대표 문제 유형, 성취기준 연결 색인, 학습 진도.
- **보강 중:** 단원별 학습 목표별 다수의 문제 유형, 어려움별 변형, 공학 도구 기반 직관 조작, 수학 오류 감수.
- **미완성:** 121개 성취기준의 모든 지식·기능·태도를 완전하게 다루는 교수학습 시나리오와 검증된 평가 체계. 현재 성취기준 코드가 연결됐다는 사실만으로 모든 세부 내용을 다 가르쳤거나 평가했다고 주장하지 않습니다.

## 콘텐츠 설계 권장 형식

개별 성취기준마다 추후 다음 단계를 콘텐츠로 관리하는 방식으로 확장합니다.

1. **개념 발견:** 움직이는 직관적 도형·교구, 학생이 직접 조작할 수 있는 3~5개 장면
2. **기초 확인:** 동일 원리의 쉬운 문제 3개 이상
3. **적용과 연결:** 다른 표상 또는 실생활 상황을 사용한 문제
4. **오개념 진단:** 틀린 선택지의 원인에 대응하는 시각적 해설
5. **성취 확인:** 정답률뿐 아니라 설명 가능 여부와 과정 수행을 확인

문항 생성과 수학적 채점은 확정된 계산 코드로 처리합니다.
