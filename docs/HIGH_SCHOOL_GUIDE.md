- 검색 안내 페이지: `/curriculum/high/`, `/curriculum/high-common-1/` 등 과목별 5개

## 수식 표기
`src/components/MathLine.tsx`가 모든 중·고등 문장을 조판합니다. 분수는 **분자 위·분모 아래**로만 보이며 빗금 표기는 화면에 나오지 않습니다.

| 원본 문자열 | 화면 |
|---|---|
| `2/5`, `√3/2`, `(x−1)/(x+2)` | 쌓은 분수 |
| `{{k|x−p}}` | 복잡한 분수(명시) |
| `a^{2/3}`, `a_{n}` | 위첨자·아래첨자 |
| `⟦1,2;3,4⟧` | 행렬 |
| `∑{k=1}{n}`, `lim{x→a}`, `∫{a}{b}` | 큰 연산자와 범위 |

채점은 원래 문자열로 하므로 화면 조판이 정답 판정에 영향을 주지 않습니다.
