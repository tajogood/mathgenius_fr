# 2022 개정 수학과 교육과정 121개 성취기준 수업 구현

## 구현 기준 (2026-11-22)

기존에는 121개 성취기준 코드를 71개 단원에 연결하기만 했습니다. 이제 각 성취기준별로 구체적인 학습 항목을 만들어, 독립적인 수업을 직접 실행할 수 있습니다.

| 범위 | 국가 성취기준 | 독립 수업 | 복합 개념 추가 확인 |
| --- | ---: | ---: | ---: |
| 1~2학년군 | 29 | 29 | 17 |
| 3~4학년군 | 47 | 47 | 33 |
| 5~6학년군 | 45 | 45 | 38 |
| **합계** | **121** | **121** | **88** |

**209개의 서로 다른 수작업 개념 확인 문제**를 제공합니다(121개 기본 + 88개 추가). 각 수업에는 83개 문제 엔진 중 주제에 맞는 자동 변형 적용 문제도 추가됩니다. 따라서 앱은 최소 330개의 확인·적용 과정(209개 고정 확인 문제 + 121개 자동 출제 단계)을 제공하되, 자동 출제 템플릿은 여러 성취기준에서 공유합니다. 330개를 모두 독립적인 문제 생성 엔진으로 세지는 않습니다.

## 학습자 화면

화면 상단에서 **단원별 학습**과 **성취기준 121개 학습** 중 하나를 선택합니다.

1. **기준 검색:** 성취기준 ID 또는 핵심 개념으로 검색, 1~2·3~4·5~6학년군 선택
2. **조작 개념 수업:** 성취기준별 목표에 따라 수학 교구를 직접 조작하며 3단계 설명
3. **기본 개념 확인:** 해당 기준의 개별 문제와 사유 확인
4. **세부 개념 확인:** 한 성취기준에 서로 다른 목표가 포함된 경우 추가 문제를 모두 통과
5. **적용 평가:** 같은 학습 주제의 자동 변형 문제로 계산과 적용 확인
6. **학습 확인 기록:** 모든 확인을 맞혀야 기준 하나를 달성으로 기록

유사한 문제를 학습하는 다른 기준이라도 **자신의 수업·확인 문제·학습 기록은 따로 관리**됩니다. 학습 기록은 `mathgenius-achievement-v1` 키로 해당 브라우저에만 저장합니다.

## 주요 확장 교구

- **6수03-14 여러 평면도형의 넓이:** 삼각형·평행사변형·사다리꼴·마름모를 전환하면서 치수를 직접 바꿔 넓이를 실시간 계산
- **6수03-10 쌓기나무의 방향별 모습:** 3×3 바닥 격자의 각 위치를 터치해 층수를 바꾼 다음 위·앞·오른쪽 모양을 따로 확인
- **6수03-06 각기둥의 전개도:** 삼각형 밑면 두 개와 사각형 옆면 세 개로 이루어진 전개도와 접힌 형태 비교
- **6수03-08 원기둥의 전개도:** 원 두 개와 직사각형 옆면 사이 대응을 표시한 전개도 펼치기/접기
- 그 밖의 성취기준은 블록, 분수 막대, 자릿값, 시계, 원, 비율, 수직선, 3차원 도형, 확률 등 기존 16개 교구와 연결됩니다.

## 교과 검수에 관한 정확한 범위

- 코드 및 목표는 **교육부 고시 제2022-33호 [별책 8] 수학과 교육과정**의 121개 기준을 대조했습니다.
- 이 앱의 수업 문구·확인 문제는 독자적으로 작성한 **개발 초안**입니다. 교육부가 인정·검정·보증한 콘텐츠가 아닙니다.
- 일부 기준은 여러 기능·과정·태도를 포함하므로 이번 209개 개념 확인 문제와 121개 적용 문제가 성취기준의 모든 하위 수행 요소를 평가한다고 주장하지 않습니다.
- 자동 생성 적용 문항의 생성 엔진은 기존 83개를 공유합니다. 특히 추론의 언어화·수학적 의사소통·실생활의 자료 수집·컴퍼스 작도 등은 실제 학습자 수행과 교사 관찰을 추가해야 합니다.
- **교사·교육과정 전문가의 문항 타당성 검수는 아직 수행하지 않았습니다.** 오류·오개념을 찾는 자동 계산 테스트와 실제 수업 검수는 다릅니다.
