# 수학천재 상호작용 학습 설계

## 설계 원칙

**눈으로만 보는 수학이 아니라 직접 조작하면서 개념을 발견하는 수학**을 구현합니다.

학생이 움직이거나 선택하면 반드시 **도형과 숫자가 함께 변하는** 구조를 사용합니다. 정답 채점은 수학 엔진이 수행하며, 학습 교구를 변화시킨 것은 원래 문제를 수정하는 행위가 아닙니다.

### 학생의 동작 → 시각적 결과 → 수학적 피드백

1. 손가락·마우스·키보드로 교구를 선택/변경/드래그합니다.
2. SVG/CSS와 React 상태가 즉시 변해 화면에 반영됩니다.
3. 현재 개수·분수·비율·각도·변환값을 확인합니다.
4. 교구를 초기 상태로 복원하고 문제와 비교합니다.
5. 문제는 결정론적 정답 엔진으로 판정합니다.

## 83개 학습 유형 → 16개 공통 교구

각 문제 주제는 `src/interactions.ts`의 `interactionForTopic`에 **반드시** 등록됩니다. 정적 시각화로 되돌아가는 기본 경로를 두지 않았습니다. 각 주제에는 학생이 무엇을 조작해야 하는지 안내 문구(`TOPIC_CHALLENGES`)가 있습니다.

| 공통 교구 | 학생이 하는 조작 | 수학적 피드백 |
| --- | --- | --- |
| 블록 세기 | 블록 터치/해제, 10개 묶음 선택, 호버 | 센 개수, 진행률 |
| 자릿값 | 자릿값 카드 선택, 선택 자리 ±1 | 수의 자리별 값 |

| 분수 막대 | 칸 색칠, 등분 수 늘리기, 원래대로 | 분자·분모, 크기·비율, 서로 다른 분수 비교 |

| 규칙 | 시작 수·변화 간격·입력 조절 | 규칙의 다음 수, 대응 관계 |
| 계산판 | 수판 터치, 약수 선택, 곱하는 수 변경 | 실제 연산 결과, 나누어떨어짐 |
| 가능성 | 구슬 색 토글, 무작위 한 개 뽑기 | 분수·백분율, 누적 시행 |
| 원 | 반지름 드래그 또는 ±1 | 지름·원주·원의 넓이 |

## 학년별 인터랙션 예

- **1학년:** 블록 하나씩 터치하여 세기, 수 가르기, 원/세모/네모 변환, 수 크기 비교
- **2학년:** 10개 묶음 만들기, 자리별 값 수정, 곱셈 배열, 시곗바늘 조작, 분류/그래프
- **3학년:** 똑같이 나누기, 나머지 확인, 분수 칸 색칠, 원의 반지름 조절, 단위 환산
- **4학년:** 각도기 드래그, 도형 밀기·뒤집기·돌리기, 사각형과 다각형, 수직선과 꺾은선그래프
- **5학년:** 분수의 등분과 약분·통분, 소수 곱셈·혼합 계산, 대칭·직육면체 전개도, 평균·가능성
- **6학년:** 비와 비율의 실시간 변화, 비례배분, 원주와 넓이, 원기둥·원뿔·구 회전, 겉넓이·부피

## 반응형 화면

- 데스크톱: 교구와 문제·선택지를 나란히 배치
- 태블릿: 화면 폭에 따라 한 열/두 열 레이아웃
- 모바일: 문제 풀이 모드에서 소개 영역을 숨기고, 문제+4개 답안을 **우선** 표시
- 세로 화면이 매우 낮을 때: 교구 내부를 별도로 스크롤 가능하게 하여 답안이 지나치게 밀리지 않도록 보호
- Hover는 마우스용 보조 효과이고 **터치/클릭/키보드에 항상 동등한 기능을 제공**해야 합니다.

## 검증

```bash
npm run build
npm test
npm run test:ui
```

- `npm test`: 71개 단원, 83개 수학 문제 주제, 121개 성취기준 코드 연결, 수학 정답·보기 검증, 모든 학습 주제의 교구 할당을 확인
- `npm run test:ui`: 클릭·색칠·값 변경·슬라이더 등의 실제 React 상태 변화를 jsdom으로 시뮬레이션
- GitHub Actions에서 두 테스트를 모두 수행

## 중요한 남은 과제

공통 교구는 모든 주제에 연결했지만, **모든 성취기준의 학습 목표에 최적화한 독자적인 조작 실험을 개별 개발한 것은 아닙니다.** 일부 복합 개념은 공통 조작 모형을 사용합니다. 앞으로는 단원별 학습 시나리오를 교사와 검토해 각 단계의 오개념 피드백과 탐구 활동을 정교하게 해야 합니다. 실제 iOS/Android 태블릿에서의 손가락 드래그·가로 모드 테스트도 필요합니다.
